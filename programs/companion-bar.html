Desktop Companion Bar

Overview

Desktop Companion Bar is a lightweight, customizable, always-on-top toolbar for Windows. Designed to enhance productivity, it provides a persistent interface for quick application launching, hotkey management, and macro execution. The application stays pinned near the taskbar (or a custom location) and ensures you have direct access to your most important tools without switching context.

Features

  • Always-On-Top Interface: Ensures your companion bar is always accessible and visible above other applications.
  • Quick Launch: Add and manage custom entries to quickly launch your favorite applications or tools.
  • Hotkey Management: Manage hotkey slots and lock them to prevent accidental triggers.
  • Macro Recorder: Record mouse movements, keyboard inputs, and window actions to create reproducible macros with custom playback speed and looping.
  • Advanced Customization: Select from built-in themes (Purple, Blue, Green, Red, Dark) or define custom background gradients, glow colors, and border colors.
  • Smart Placement: Automatically snaps relative to your Windows taskbar location, with integrated arrow indicators and placement guides for seamless repositioning.
  • Global Hotkeys: Use global keyboard shortcuts to show/hide the bar or trigger an emergency lock.

Technologies Used

  • C# / .NET 8.0: Core backend logic and runtime.
  • WPF (Windows Presentation Foundation): Modern, hardware-accelerated UI rendering.
  • MVVM Architecture: Follows Model-View-ViewModel principles for clean separation of concerns.
  • Windows APIs / Interop: Utilized for precise taskbar detection, window positioning, and forced top-most behavior.

Setup & Installation

Prerequisites

  • Windows OS (Windows 10 or later recommended).
  • .NET 8.0 Desktop Runtime or later.
  • Visual Studio 2022 (if building from source).

Building from Source

  1. Clone or download the repository.
  2. Open the solution file CompanionBar.sln (or CompanionBar.csproj) in Visual Studio 2022.
  3. Ensure the target framework is set to .NET 8.0.
  4. Restore NuGet packages if necessary.
  5. Build the solution (Ctrl + Shift + B).
  6. Run the project (F5 or Ctrl + F5).

Usage

  1. Launch: Start the application. The bar will appear and snap to the nearest edge of your screen relative to the taskbar.
  2. Move: Click and drag any empty space on the bar to reposition it. Visual guides will aid you in placement.
  3. Menu: Click the "Menu" button to open the settings window. Here, you can configure colors, themes, macros, and global hotkey bindings.
  4. Macros: Use the Macro tab in the settings menu to start/stop recording your keystrokes and mouse actions.
