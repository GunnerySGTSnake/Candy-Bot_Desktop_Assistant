Stripchat Exporter

A comprehensive Windows desktop application for extracting and downloading video clips and trailers from Stripchat. Built with C#, .NET 8, and WPF, this tool streamlines the process of fetching authenticated content, automatically parsing JSON archives, and safely downloading streams via direct HTTP or FFmpeg remuxing.

Features

  • Smart Video Downloading: Supports both standard direct MP4 downloads via HTTP and seamless remuxing of HLS streams (.m3u8 / .ts) into .mp4 using bundled FFmpeg, preserving raw stream quality without re-encoding.
  • Browser Cookie Authentication: Optionally decrypts local session cookies from Chrome, Edge, Brave, or Vivaldi (bypassing DPAPI/AES-256-GCM encryption on Windows) to automatically fetch authenticated APIs and content without requiring manual login.
  • JSON Parsing: Allows manually pasting raw JSON payloads to easily discover and extract hundreds of clips and trailers.
  • Local Download History Tracking: Uses a local SQLite database to record successfully downloaded videos and trailers. This allows the UI to automatically flag duplicate files and prevent redownloading items from your history.
  • Queue Resuming: Automatically saves your pending download queue when the app is closed. On the next start, it will prompt to resume any interrupted downloads.
  • Built-in Mp4 Inspector: Reads MP4 headers (moov/mvhd atoms) efficiently to determine local file durations without loading the entire media file.
  • Automatic Updates: Includes an update service that checks for the latest app versions on launch.

Technologies Used

  • Language: C# 12
  • Framework: .NET 8.0 (Windows Desktop)
  • UI: Windows Presentation Foundation (WPF)
  • Database: SQLite (Microsoft.Data.Sqlite)
  • JSON Processing: Newtonsoft.Json
  • Video Processing: FFmpeg
  • Installer: Inno Setup Compiler

Setup and Installation

Prerequisites

  • .NET 8.0 Desktop Runtime
  • Visual Studio 2022 (or the .NET CLI dotnet build)
  • FFmpeg: The application expects ffmpeg.exe to be present next to the built executable.
  • Inno Setup (Optional): If you want to build the .exe installer.

Building from Source

  1. Clone or download the repository.
  2. Navigate to the StripchatExporter project directory.
  3. Build the project using the .NET CLI: cmd cd StripchatExporter dotnet build -c Release Alternatively, open the folder in Visual Studio 2022 and build from the IDE.
  4. Download the latest FFmpeg binaries for Windows and place ffmpeg.exe inside the output directory (e.g., StripchatExporter/bin/Release/net8.0-windows/).

Creating the Installer

To bundle the application into a standalone Windows installer: 1. Ensure the app is compiled in Release mode and the executable is placed in the Release/ directory at the project root. 2. Ensure ffmpeg.exe and ffprobe.exe are located at C:\ffmpeg (or update the #define FfmpegDir path in installer.iss). 3. Open installer.iss using Inno Setup Compiler. 4. Compile the script. The generated setup file will be placed in the Installer/ directory.
