Candy-Bot Desktop App

A versatile, feature-rich desktop assistant application built in C# WPF (.NET 9). Candy-Bot acts as an all-in-one desktop companion offering an interactive animated desktop widget with voice support, unrestrictive AI chat and roleplay capabilities, image and document generation, DJ booking and Camelot wheel tools, as well as robust PC automation like multi-drive file search and Twilio/Phone Link SMS integration.

🚀 Core Technologies

  • C# / .NET 9: Application framework (Target: net9.0-windows10.0.19041.0)
  • WPF (Windows Presentation Foundation): UI framework with custom UI elements, live theming, and animations.
  • Venice AI API: Backend engine for unrestricted text generation, extensive roleplay chat, and image generation.
  • ElevenLabs API: Text-to-Speech (TTS) for lifelike character voice generation.
  • Twilio API & Windows Phone Link: For automated SMS sending/receiving and incoming call notifications natively on Windows.
  • Gradio / Hugging Face Spaces: Additional image generation support via Gradio services.
  • Microsoft WebView2: Embedded modern web browser.
  • Newtonsoft.Json: Data management, settings, and local profiles.

✨ Key Features

  • Floating Desktop Widget: An animated, always-on-top companion widget providing quick access to all tools. Features include voice feedback, theme-awareness, and a "Privacy Mode" triggered via global hotkeys (Scroll Lock).
  • AI Chat & Unrestricted Roleplay Engine: Deep roleplay mode with multi-character support. Features highly customizable character profiles (name, age, sex, appearance, personality, relationship, kink tags), adjustable intensity sliders, and save/load chat histories.
  • AI Generators:
  • Image Generation: Prompt-to-image integration natively in the app.
  • Document & Code Generation: Specialized assistants for writing documents and generating code.
  • DJ Engine / Camelot Tool: Specialized tools for DJ track management, harmonic mixing (Camelot wheel), and gig planning.
  • Multi-Drive File Search: A fast search utility across the user's PC.
  • SMS & Phone Integration: Read and reply to text messages via Twilio API or automated Windows Phone Link UI automation.
  • Persona Library: Save and load AI character personas, family tree configurations, and user profiles to quickly resume roleplay sessions.

🛠️ Setup & Installation

  1. Prerequisites:
  2. Windows 10/11
  3. .NET 9.0 Desktop Runtime
  4. Visual Studio 2022 (if building from source)
  5. Clone the Repository: Download or clone the project folder.
  6. Open Project: Open CandyBotApp.csproj in Visual Studio.
  7. Restore Dependencies: NuGet will automatically restore necessary packages:
  8. Autoupdater.NET.Official
  9. Microsoft.Web.WebView2
  10. Newtonsoft.Json
  11. System.Speech
  12. Build & Run: Press F5 to build and launch the application.
  13. Configuration: Upon first launch, right-click the widget to access Settings. Enter your required API keys (Venice AI, ElevenLabs, Twilio) for full functionality.

📁 Project Structure highlights

  • /Services/: API service connectors (VeniceAIService.cs, ElevenLabsVoiceService.cs, CandyBotSmsService.cs, CandyBotMcpBridge.cs, etc.)
  • /Models/: Data structures and state definitions.
  • /PythonScripts/: Additional scripts that the backend may invoke.
  • CandyBotDesktopWidget.xaml/cs: The main entry point floating widget.
  • CandyBotRolePlayWindow.cs: Unrestricted Roleplay UI handling.
  • CandyBotDJWindow.cs & CamelotEngine.cs: DJ Engine functionality.
