🎵 Candy-Bot: Desktop Companion & AI Ecosystem

"To Help Others Find Their Voices" - In Memory of DJCANDY (Candy)

Candy-Bot is a comprehensive AI-powered ecosystem combining a feature-rich Windows Desktop Widget (WPF) with a robust Node.js backend API. It serves as an interactive, always-on-top animated desktop companion capable of advanced conversations, image/video/music generation, deep file organization, and intelligent web searching.

🌟 Key Features

🖥️ Desktop Widget (Frontend)

  • Always-On-Top Companion: An animated, bobbing avatar with glowing pink effects that lives persistently on your Windows desktop.
  • Voice Feedback & TTS: Built-in Text-to-Speech (TTS) integration announcing actions, reading responses, and providing system notifications via animated speech bubbles.
  • Context Menu & Quick Chat: Right-click for a full tool menu; left-click to open the instant text chat interface.
  • AI Integrations: Direct UI access to the Code Assistant, Image Generation, Document Generation, and Web Browsing capabilities.
  • Advanced File Management: Multi-Drive File Search, Enhanced File Search, and File Organizer built straight into the UI.
  • Auto-Positioning: Remembers your preferred screen position and intelligently adapts to multi-monitor setups.

⚙️ AI Backend API

  • Advanced LLM Integration: Powered by the Anthropic Claude API for nuanced, character-driven interactions with conversational memory.
  • Multimedia Generation: Integrations with DALL-E/Stability AI/Replicate for images, ElevenLabs/Suno for voice and music, and Runway ML for video.
  • Persistent Memory: Uses Azure Cosmos DB for robust conversation history storage.
  • Web Intelligence: Integrated Brave Search and Serper API for real-time web awareness.

🔍 Network Utilities

  • A collection of Python scripts (deep_trace_ip.py, generate_ip_report_pdf.py, etc.) for network probing, deep IP tracing, and generating diagnostic PDF reports.

🛠️ Technology Stack

  • Frontend (Desktop App): C#, WPF, .NET 8.0/9.0, Microsoft WebView2, System.Speech, Newtonsoft.Json.
  • Backend (API Server): Node.js, Express.js, Azure Cosmos SDK, Axios.
  • Scripting & Utils: Python 3.x (Network analysis and reporting).

🚀 Getting Started

Prerequisites

  • Node.js 18+ (for the backend server)
  • .NET 8.0+ SDK (for compiling and running the WPF Desktop Widget)
  • Python 3.x (optional, for specific networking scripts)

1. Setting up the Backend API

  1. Open a terminal in the project root.
  2. Install Node dependencies: bash npm install
  3. Copy .env.example to .env and fill in your necessary API keys (Anthropic, OpenAI, Cosmos DB, ElevenLabs, etc.).
  4. Start the backend server: bash npm start (The server will run on localhost:3000 by default)

2. Launching the Desktop Widget

You can run the pre-configured scripts to easily start the widget from your terminal or file explorer: - Run LAUNCH_WIDGET.bat or RUN_WIDGET.bat / RUN_WIDGET.ps1.

Alternatively, build and run via source: 1. Open the project in Visual Studio. 2. Ensure the required NuGet packages are restored (Microsoft.Web.WebView2, System.Speech, Newtonsoft.Json, etc.). 3. Build and Run the project. The floating Candy-Bot widget will appear on your screen.

📁 Repository Structure

  • /CandyBotApp - The core C# WPF application and widget logic (including settings, logs, and generator windows).
  • /src - Node.js Express backend controllers, routes, and AI logic services.
  • /Controls & /Converters - Custom WPF UI elements and data converters.
  • /Images & /Models - UI assets (like the Candy-Bot avatar) and data transfer models.
  • /*.xaml & /*.cs - Various feature windows for chat, file search, personalities, and settings.
  • /*.py - Python utility scripts for device probing and IP tracing.
  • /publish* - Compiled release builds and installer files.

🎨 Customization & Settings

The widget is highly customizable through its built-in Settings window (accessible via right-click): - Voice: Toggle Text-to-Speech on/off and adjust the speech rate. - Personalities: Switch the AI's persona (e.g., Helpful, Funny, Professional). - Appearance: Adjust themes, including the signature Pink glow versus standard UI borders. - Positioning: Snap to 9 different predefined screen sectors.
